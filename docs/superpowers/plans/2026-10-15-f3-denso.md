# f3 Motion denso — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** o f3 vira o estilo do reel de referência — tela dividida com card do falante, painéis de
2–5 s com cara de interface cobrindo ≥ 85% do Short, ícones e ilustrações desenhados por código e
um tema por assunto.

**Architecture:** o pipeline do f3 continua o mesmo (LLM → JSON validado → código monta HTML/GSAP).
Mudam: o catálogo (`motion_params`), o ritmo (`motion_ritmo`), o prompt/schema (`motion_prompt`),
o HTML/animação dos componentes, o template e o resultado do motion, que passa a levar o tema e
os SVGs. Módulos novos: `motion_tema` (paletas → CSS), `motion_icones` (ícones de traço escritos
aqui, sem download), `motion_svg` (sanitizador + chamada do SVG livre + cache) e `motion_planta`
(planta isométrica).

**Tech Stack:** Python 3.13, FastAPI, HyperFrames 0.8.104 + GSAP 3.14.2, `claude -p` (sonnet).

**Spec:** `docs/superpowers/specs/2026-10-15-f3-denso-design.md` · Pesquisa: `pesquisa/05-reel-referencia-f3.md`

## Global Constraints

- Check depois de cada task: `ruff check src tests`, `mypy src`, `pytest -q`, `node --check` no JS mexido.
- LLM devolve JSON validado, nunca HTML de layout; o único markup do LLM é o SVG da `ilustracao`,
  que só entra re-serializado pelo sanitizador. Todo texto do LLM em HTML passa por `html.escape`;
  o JavaScript só leva ids gerados e números.
- Números na tela só os ditos (`motion_numeros`), inclusive dentro do SVG.
- Nada de default silencioso; SVG ruim nunca derruba o corte (vira ícone + rótulo, motivo registrado).
- Ícones: escritos à mão neste repo (sem baixar pacote) — a spec citava Lucide; ruling no ledger.
- Arquivos ≤ 400–500 linhas; funções < 50 linhas; dividir por responsabilidade.
- Sem commit até o fim; no fim, commit só dos arquivos desta frente (o branch tem mudanças de SEO
  de outra frente em `pipeline.py`, `servidor.py`, `rotas.py`, `rotas_cortes.py`).

## Review Focus

- Corte sem nada mostrável em vários trechos: o ritmo não pode aceitar painel inventado nem deixar
  painel velho na tela — a faixa vazia mostra o rótulo (teste em Task 5/8).
- SVG com `<script>`, `on*`, `href`, `foreignObject`, entidade/DOCTYPE, cor fora da paleta ou
  número não dito: recusado, com motivo (Task 4).
- Cache antigo (formato 1) de cortes já feitos: ignorado e refeito, nunca erro (Task 6).
- Tema escolhido no editor que muda depois do LLM: refaz o HTML e o SVG, não as cenas (Task 6/9).
- Respiro colado em outro, antes de 6 s ou mais de 2: recusado (Task 5).

### Task 4: SVG livre
**Files:** create `src/cortes/render/motion_svg.py`; test `tests/test_render_motion_svg.py`.
**Produces:** `sanitizar(svg: str, cores: frozenset[str]) -> str` (ErroSvg com motivo: DOCTYPE/
ENTITY, XML inválido, raiz não svg, viewBox ≠ "0 0 1000 700", elemento/atributo fora da lista
branca, `on*`, `href`, `url(` não-`#id`, cor fora da paleta, > 8 KB, > 400 elementos; devolve SVG
re-serializado só com o permitido), `textos_svg(svg) -> list[str]`, `svg_da_cena(d_corte, k,
il: Ilustracao, tema, ditos: list[str], chamar) -> tuple[str | None, str | None]` (svg ou motivo;
cache em `motion/svg/<k>.json` pela chave descrição+tema; erro de LLM vira motivo, não exceção),
`SCHEMA_SVG`, `SISTEMA_SVG`, `MODELO_SVG = "sonnet"`.
**Tests:** caso válido re-serializado sem perder geometria; um caso negativo por regra; texto com
número não dito → motivo; cache não chama o LLM duas vezes; tema diferente chama de novo; ErroLLM
vira motivo.

### Task 5: Ritmo
**Files:** rewrite `render/motion_ritmo.py`, `render/motion_cobertura.py`; modify `render/motion.py`

**Produces:** `CAPA_FIM_S = 2.0` (em motion.py), `GANCHO_S = 2.0`, `DUR_MIN_S = 2.0`,
`DUR_MAX_S = 5.0`, `RESPIRO_MIN_S = 1.5`, `RESPIRO_MAX_S = 3.0`, `RESPIROS_MAX = 2`,
`RESPIRO_DEPOIS_S = 6.0`, `ILUSTRACOES_MAX = 3`, `COBERTURA_MIN = 0.85`, `VAO_LONGO_S = 3.0`.
`ritmo(cenas, dur, fixas)` com as regras da spec §4 (sem gap de rosto entre painéis; aparar o que
